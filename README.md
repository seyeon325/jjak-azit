# 짝선짝후 아지트 (1차)

AR·VR미디어디자인전공 선후배 교류 행사 **짝선짝후 2026PAIR**용 웹 멀티플레이 메타버스 공간입니다.
참가자는 휴대폰 브라우저로 링크에 접속해 자기 캐릭터를 만들고, 광장을 돌아다니며 서로를 만납니다.
빔프로젝터에는 `/screen` 관전 화면을 띄워 모두의 움직임을 함께 봅니다.

- 참가자 화면: `http://주소/`
- 운영자 관전 화면(빔프로젝터): `http://주소/screen`

---

## 1. 처음 한 번만: 준비

1. **Node.js 20 이상**을 설치합니다 → https://nodejs.org (LTS 버전, 설치 마법사에서 '다음'만 누르면 됩니다)
2. 이 폴더에서 터미널(PowerShell)을 열고 아래 명령으로 필요한 패키지를 설치합니다.

```bash
npm install
```

> `install-scripts` 관련 경고가 보여도 정상입니다. 그대로 진행하면 됩니다.

---

## 2. 실행하기

### 행사 당일 / 실제 사용 (권장)

```bash
npm run build
```

```bash
npm start
```

터미널에 이런 안내가 나옵니다.

```
  짝선짝후 아지트 서버가 시작됐어요!
  - 이 컴퓨터: http://localhost:3000
  - 같은 Wi-Fi: http://192.168.0.12:3000
```

- 노트북 브라우저에서 `http://localhost:3000/screen` 을 열어 빔프로젝터에 띄웁니다. (`F` 키 = 전체 화면)
- 관전 화면 오른쪽 아래 **QR 코드**를 참가자들이 휴대폰 카메라로 찍으면 바로 입장합니다.
- 종료: 터미널에서 `Ctrl + C`

### 개발 중 (코드를 고치면 바로 반영)

```bash
npm run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다. 관전 화면은 `http://localhost:5173/screen` 입니다.

## 3. 환경변수 (선택)

없어도 기본값으로 동작합니다. 바꾸고 싶을 때만 `.env.example` 을 참고하세요.

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트. 배포 서비스는 보통 자동으로 지정합니다. |
| `PUBLIC_URL` | (자동) | 관전 화면 QR 코드에 넣을 주소. 배포했다면 `https://내주소` 로 지정하세요. |
| `MAX_PLAYERS` | `60` | 최대 동시 접속 인원 |
| `RECONNECT_GRACE_SEC` | `45` | 연결이 끊긴 참가자를 기다리는 시간(초). 이 안에 돌아오면 같은 캐릭터로 복귀합니다. |

PowerShell에서 한 번만 지정해서 실행하려면:

```bash
$env:PUBLIC_URL="https://jjak-azit.onrender.com"; npm start
```

## 4. 테스트 방법

### 자동 점검 (서버가 켜져 있는 상태에서)

```bash
npm run selftest
```

입장 → 이동 동기화 → 연결 끊김 표시 → 같은 캐릭터로 복귀 → 벽 통과 차단 → 퇴장을 확인하고 `모든 점검 통과!` 를 출력합니다.
(기본 주소는 `http://localhost:3000` 입니다. 배포한 서버를 점검하려면 `npx tsx scripts/selftest.ts https://내주소` 처럼 주소를 넣으세요.)

### 30명 부하 테스트

```bash
npm run bots -- 30
```

가짜 참가자 30명이 들어와 광장을 돌아다닙니다. 관전 화면과 휴대폰에서 끊김 없이 움직이는지 확인하세요. 종료는 `Ctrl + C`.

### 직접 여러 명으로 해보기

- 브라우저 탭 여러 개: 한 브라우저는 캐릭터를 하나만 기억하므로, 두 번째 탭은 주소 뒤에 `?slot=2` 를 붙이세요. (예: `http://localhost:5173/?slot=2`)
- 휴대폰: 노트북과 **같은 Wi-Fi**에 연결한 뒤 터미널에 나온 `같은 Wi-Fi` 주소로 접속합니다.
- 새로고침해 보세요 → 같은 캐릭터, 같은 자리로 돌아옵니다.
- 서버를 껐다 켜 보세요 → 참가자 화면이 "다시 연결됐어요!"를 띄우고 자동으로 재입장합니다.

### 체크리스트 (1차 완료 기준)

- [x] 링크로 접속 → 닉네임 · 선배/후배 · 캐릭터(외형 8종 × 옷 색상 8종) 선택 → 입장
- [x] PC: WASD/방향키, 휴대폰: 화면 왼쪽 아래 조이스틱으로 이동
- [x] 여러 브라우저에서 서로의 캐릭터가 실시간으로 보임 (보간으로 부드럽게)
- [x] 접속 인원, 입장·퇴장, 연결 끊김 상태가 반영됨
- [x] `/screen` 운영자 전체 관전 화면 (전체 보기 / 참가자 따라가기 / QR)
- [x] 벽·나무·연못·놀이기구 충돌, 캐릭터 겹침 완화, 이름표 겹침 시 위로 쌓기

## 5. 배포 (인터넷 주소로 공개하기)

행사장 Wi-Fi가 기기끼리 통신을 막는 경우(학교 Wi-Fi에서 흔합니다)에는 인터넷에 배포하는 게 가장 확실합니다.
WebSocket을 지원하는 서비스여야 하며, 아래는 **Render** 기준입니다 (`render.yaml` 포함).

1. 이 폴더를 GitHub 저장소에 올립니다.
2. https://render.com 가입 → **New → Blueprint** → 저장소 선택 → 배포.
   (직접 만들 경우: Web Service / Build `npm ci && npm run build` / Start `npm start`)
3. 배포 주소가 나오면 환경변수 `PUBLIC_URL` 에 그 주소를 넣고 다시 배포합니다 (QR 코드용).

> 무료 요금제는 한동안 접속이 없으면 잠들어서 첫 접속이 30초~1분 걸립니다. **행사 시작 10분 전에 미리 한 번 접속**해 깨워두세요.
> 서버를 재배포/재시작하면 참가자는 자동으로 다시 입장하지만, 행사 중에는 재배포하지 않는 것을 권장합니다.

Railway, Fly.io 등 다른 Node.js 호스팅도 같은 명령(`npm run build` → `npm start`)으로 동작합니다.

## 6. 구조

```
shared/            클라이언트·서버 공용
  constants.ts     맵 크기, 틱/전송 주기, 이동 속도 등
  protocol.ts      네트워크 이벤트 타입 (여기에 먼저 선언 → 양쪽에서 타입 검사)
  map.ts           광장 지형·소품·구역·충돌 격자 (서버도 같은 데이터로 검증)
server/
  index.ts         Express(정적 파일·/api/info) + Socket.IO (입장·복귀·이동)
  sessions.ts      세션 토큰 ↔ 참가자, 끊김 유예 타이머
  rooms/Room.ts    룸 공통: 참가자 상태, 15Hz 위치 브로드캐스트, 이동 검증
  rooms/PlazaRoom.ts  메인 광장 (맵 충돌 규칙)
  validation.ts    닉네임/프로필/이동 입력 정리
client/src/
  main.ts          화면 흐름 (접속 → 로그인/복귀 → 게임, /screen 관전)
  net/Network.ts   소켓 연결, 토큰 저장
  state/WorldStore.ts  참가자 목록, 서버 시간 동기화, 위치 보간
  game/            Phaser 3
    scenes/WorldScene.ts  맵 렌더, 내 캐릭터 이동·전송, 원격 보간, 카메라
    entities/Avatar.ts    캐릭터 스프라이트·애니메이션
    art/           픽셀 아트를 코드로 생성 (캐릭터, 바닥, 소품) — 외부 이미지 없음
  ui/              DOM UI (로그인, HUD, 조이스틱, 이름표, 관전 화면)
scripts/           bots.ts (부하 테스트), selftest.ts (자동 점검)
```

### 네트워크 동작 요약

- 클라이언트는 자기 위치를 초당 15회 보냅니다 (변화가 있을 때만).
- 서버는 속도와 벽 통과를 검사하고, 바뀐 참가자 위치만 초당 15회 묶어서 보냅니다. 3초마다 전체 위치를 다시 보내 유실을 보정합니다.
- 다른 참가자는 약 140ms 뒤의 과거 시점을 보간해 그리기 때문에 네트워크가 흔들려도 부드럽게 움직입니다.
- 새로고침·잠깐 끊김: 브라우저에 저장된 세션 토큰으로 `resume` → 같은 캐릭터로 복귀. 그동안 다른 사람에게는 반투명 + "연결 끊김"으로 보입니다.
- 서버 재시작: 토큰이 사라져도 저장된 프로필과 마지막 위치로 자동 재입장합니다.

### 2차·3차 확장 포인트

| 기능 | 붙이는 곳 |
| --- | --- |
| 메시지 게시판 | `protocol.ts`에 `board:*` 이벤트 추가 → 서버에 SQLite(예: `better-sqlite3`) 저장소 → 게시판 구역(`zone.id === 'board'`)에서 UI 열기 |
| 대화·말풍선·이모트 | `WorldOverlay`(DOM 레이어)에 말풍선 요소 추가, 서버 `Room`에서 같은 채널로 브로드캐스트 |
| 놀이터 장난 기믹 | `WorldScene`의 소품(`slide`, `swing` 등)에 상호작용 반경 + 서버 이벤트 |
| '과제 괴물' 레이드 | `Room`을 상속한 `RaidRoom` 생성 → 포털 구역에서 룸 이동 → 클라이언트에 `RaidScene` 추가 |

구역의 개발 단계는 `shared/map.ts`의 `phase` 값(1·2·3)으로 관리하며, 화면의 "준비 중"·"2차 예정" 표시도 여기에서 나옵니다.

## 7. 문제 해결

- **휴대폰에서 접속이 안 돼요** → 노트북과 같은 Wi-Fi인지 확인하세요. 학교 Wi-Fi는 기기 간 통신을 막는 경우가 많으니, 노트북 핫스팟을 쓰거나 5장의 방법으로 배포하세요. Windows 방화벽 허용 창이 뜨면 "허용"을 누르세요.
- **QR 코드 주소가 이상해요** → `PUBLIC_URL` 을 지정하세요.
- **"다른 화면에서 접속했어요"** → 같은 브라우저의 다른 탭에서 같은 캐릭터로 들어간 경우입니다. 테스트할 때는 `?slot=2` 를 쓰세요.
- **포트가 이미 사용 중** → 다른 서버가 3000번을 쓰고 있습니다. `$env:PORT=3100; npm start` 처럼 바꾸세요.
