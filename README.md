# 짝선짝후 아지트 (2차)

AR·VR미디어디자인전공 선후배 교류 행사 **짝선짝후 2026PAIR**용 웹 멀티플레이 메타버스 공간입니다.
참가자는 휴대폰 브라우저로 링크에 접속해 자기 캐릭터를 만들고, 광장을 돌아다니며 서로를 만납니다.
빔프로젝터에는 `/screen` 관전 화면을 띄워 모두의 움직임을 함께 봅니다.

- 참가자 화면: `http://주소/`
- 관전 화면(빔프로젝터): `http://주소/screen`
- 운영자 페이지: `http://주소/admin` (비밀번호 로그인 → 관전 화면 + 관리 패널)

### 지금 할 수 있는 것

| 공간 | 내용 |
| --- | --- |
| 입장 | 닉네임 → 학년(1~4학년·기타는 직접 입력) → 선배/후배 → 팀(6팀) → 캐릭터 12종 |
| 중앙 광장 · 메시지 게시판 | 쪽지 쓰기(100자, 익명 선택) · 최신순/랜덤 · 댓글 · 하트 · 내 글 수정/삭제 |
| 채팅 | 오른쪽 위 **채팅** — 일반(모두) / 모닥불(주변 사람만) / 벤치(옆자리 1명만, 비공개) |
| 표정·동작 | 오른쪽 위 **표정** — 이모티콘 8종, 손 흔들기·브이·점프·빙글·앉기·춤·놀람 |
| 다른 참가자 | 가까이 가거나 캐릭터를 누르면 인사·하트·박수·종이비행기·물풍선·뿅망치·함께 춤추기·따라가기 |
| 푸드트럭 (왼쪽 위) | **메뉴 보기** → 간식 선택 → 손에 들고 다니기 → **먹기** |
| 카피바라 온천 (아래 가운데) | **온천 들어가기** → 물속에서 천천히 이동 → **나가기** |
| 모닥불 쉼터 (왼쪽 아래) | 통나무에 **앉기**, 모닥불 대화, 랜덤 질문 카드 |
| 놀이터 (오른쪽 아래) | 그네(타기·밀기, 5번 밀면 '퐁!'), 미끄럼틀, 2인 시소, 스프링 |
| 벤치 (광장) | 둘이 나란히 앉으면 둘만의 벤치 대화 |
| 게임 포털 | 3차 업데이트 예정 |

메뉴 → 내 캐릭터에서 **이름표 숨기기**(내 화면만)와 **장난 받지 않기**(물풍선·뿅망치·그네 밀기 거부)를 켤 수 있어요.

PC에서는 상호작용 버튼을 **E** 키로도 누를 수 있어요.

## 1. 처음 한 번만: 준비

1. **Node.js 20 이상**을 설치합니다 → https://nodejs.org (LTS 버전, 설치 마법사에서 '다음'만 누르면 됩니다)
2. 이 폴더에서 터미널(PowerShell)을 열고 아래 명령으로 필요한 패키지를 설치합니다.

```bash
npm install
```

> `install-scripts` 관련 경고가 보여도 정상입니다. 그대로 진행하면 됩니다.

---

## 2. 실행하기

### 행사 당일 / 실제 사용 (권장)

```bash
npm run build
```

```bash
npm start
```

터미널에 이런 안내가 나옵니다.

```
  짝선짝후 아지트 서버가 시작됐어요!
  - 이 컴퓨터: http://localhost:3000
  - 같은 Wi-Fi: http://192.168.0.12:3000
```

- 노트북 브라우저에서 `http://localhost:3000/screen` 을 열어 빔프로젝터에 띄웁니다. (`F` 키 = 전체 화면)
- 관전 화면 오른쪽 아래 **QR 코드**를 참가자들이 휴대폰 카메라로 찍으면 바로 입장합니다.
- 종료: 터미널에서 `Ctrl + C`

### 개발 중 (코드를 고치면 바로 반영)

```bash
npm run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다. 관전 화면은 `http://localhost:5173/screen` 입니다.

## 3. 환경변수 (선택)

없어도 기본값으로 동작합니다. 바꾸고 싶을 때만 `.env.example` 을 참고하세요.

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트. 배포 서비스는 보통 자동으로 지정합니다. |
| `PUBLIC_URL` | (자동) | 관전 화면 QR 코드에 넣을 주소. 배포했다면 `https://내주소` 로 지정하세요. |
| `MAX_PLAYERS` | `60` | 최대 동시 접속 인원 |
| `RECONNECT_GRACE_SEC` | `45` | 연결이 끊긴 참가자를 기다리는 시간(초). 이 안에 돌아오면 같은 캐릭터로 복귀합니다. |
| `ADMIN_PASSWORD` | (없음) | **운영자 페이지 비밀번호. 꼭 설정하세요.** 없으면 서버가 켜질 때마다 임시 비밀번호를 로그에 표시해요 (개발 모드는 `azit-dev`). |
| `DATA_DIR` | `data` | 게시판·설정 저장 폴더 |
| `BOARD_FILE` | `data/board.json` | 게시판 저장 파일 위치 |

PowerShell에서 한 번만 지정해서 실행하려면:

```bash
$env:PUBLIC_URL="https://jjak-azit.onrender.com"; npm start
```

## 4. 테스트 방법

### 자동 점검 (서버가 켜져 있는 상태에서)

```bash
npm run selftest
```

실제 소켓 클라이언트 여러 개가 동시에 접속해 85개 항목을 확인하고 `모든 점검 통과!` 를 출력합니다.
입장·학년(기타 직접 입력)·팀, 이동·벽, 끊김/복귀, 푸드트럭·온천, 게시판(익명·수정·삭제·댓글·하트·소유권), 채팅(일반·모닥불·벤치 수신 범위), 좌석, 그네(밀기·퐁)·미끄럼틀·시소, 이모티콘·포즈·장난(쿨타임·거리·거부), 따라가기 요청, 운영자 권한(로그인·팀 배정·채팅 제한·공지·단체 사진·게시판 삭제·CSV)까지 확인해요.
운영자 점검은 `ADMIN_PASSWORD` (기본 `azit-dev`) 로 로그인합니다. 배포 서버에는 게시판에 쪽지를 남기지 않는 `npx tsx scripts/prodcheck.ts https://주소` 를 쓰세요.
(기본 주소는 `http://localhost:3000` 입니다. 배포한 서버를 점검하려면 `npx tsx scripts/selftest.ts https://내주소` 처럼 주소를 넣으세요.)

### 30명 부하 테스트

```bash
npm run bots -- 30
```

가짜 참가자 30명이 들어와 광장을 돌아다니고, 가끔 푸드트럭에서 간식을 사 먹거나 온천에 들어갑니다. 관전 화면과 휴대폰에서 끊김 없이 움직이는지 확인하세요. 종료는 `Ctrl + C`.

### 직접 여러 명으로 해보기

- 브라우저 탭 여러 개: 한 브라우저는 캐릭터를 하나만 기억하므로, 두 번째 탭은 주소 뒤에 `?slot=2` 를 붙이세요. (예: `http://localhost:5173/?slot=2`)
- 휴대폰: 노트북과 **같은 Wi-Fi**에 연결한 뒤 터미널에 나온 `같은 Wi-Fi` 주소로 접속합니다.
- 새로고침해 보세요 → 같은 캐릭터, 같은 자리로 돌아옵니다.
- 서버를 껐다 켜 보세요 → 참가자 화면이 "다시 연결됐어요!"를 띄우고 자동으로 재입장합니다.

## 운영자 페이지 (/admin)

1. `https://주소/admin` 접속 → 비밀번호 입력 (`ADMIN_PASSWORD`)
2. 관전 화면 오른쪽에 관리 패널이 열려요. 오른쪽 위 ✕(또는 **A** 키)로 접고, 오른쪽 아래 **운영자 메뉴** 버튼으로 다시 열어요.
   - **대시보드**: 접속 인원·숨바꼭질 상태·이스터에그·상품권 현황
   - **접속자 관리**: 학년·선후배 확인, 팀 배정(재접속해도 유지), 채팅 제한, **추적**
   - **메시지 게시판 관리**: 익명 글도 실제 작성자 확인, 쪽지·댓글 삭제, CSV 내려받기
   - **전체 공지** · **관전 카메라** · **단체 사진 모드**(닉네임·팀·말풍선 숨기기 포함)
   - **학회장을 찾아라!**: 숨바꼭질 시작·종료, 최근 회차 기록
   - **숨바꼭질 당첨 · 상품 지급 기록**: 당첨자, 지급 완료 표시, 당첨 취소, CSV
   - **이스터에그 관리**: 조건값·사용 여부·전체/개인 알림, 최초 달성자, 기록 초기화(해당 항목만), CSV
   - **상품 관리**: 배달의민족 상품권 4장 = 숨바꼭질 1 + 3차 랜덤 추첨 3 (할당은 여기서만 변경)
   - **설정**: 팀 이름, 로그아웃
3. 관전 카메라: **1** 전체 · **2** 모두 따라가기 · **3** 자유 카메라(끌기·휠·방향키·+/-) · **L** 참가자 검색/추적 · **Q** QR · **F** 전체 화면 · **Esc** 전체로

### 학회장을 찾아라! (숨바꼭질) 진행 방법

1. 학회장은 휴대폰이나 PC로 **참가자 화면**(아지트 주소)에 들어가 캐릭터를 만든 뒤, 메뉴(≡) → **내 캐릭터** → **학회장 로그인**에 운영자 비밀번호를 입력해요. 화면 오른쪽에 **★ 학회장** 버튼이 생겨요.
2. **★ 학회장** → 수색 시간 선택 → **숨바꼭질 시작** (운영자 페이지의 ‘학회장을 찾아라!’에서도 시작 가능)
3. 다른 모든 화면(빔프로젝터 포함)이 15초 동안 가려져요. 이 동안 학회장 위치는 서버가 아무에게도 보내지 않아요. 숨을 곳으로 이동하세요.
4. 15초 뒤 그 자리가 숨은 위치로 확정되고(학회장은 움직일 수 없음), 참가자는 중앙 광장에서 출발해요. 이름표·팀·칭호는 자동으로 숨겨져요.
5. 학회장 바로 옆에 가면 **찾았다!!** 버튼이 나와요. 가장 먼저 누른 1명이 우승 → 모든 화면에 발견 장면 → 배달의민족 상품권 1장 당첨이 기록돼요.
6. 상품권을 전달한 뒤 운영자 페이지 **당첨 기록**에서 ‘지급 완료로 표시’를 눌러주세요.
- 다시 해도 상품권은 중복 배정되지 않아요 (우승은 기록). 학회장 연결이 끊기면 일시정지했다가 45초 안에 돌아오면 이어서 진행하고, 아니면 자동 취소돼요.

### 이스터에그 · 칭호
- 8가지 숨은 업적(온천 지박령·그네 중독자·수뭉이빵 애호가·모닥불 수호자·춤신춤왕·장난꾸러기·비밀 발견자·아지트 탐험가)을 **가장 먼저** 달성한 1명이 칭호를 받아요. 조건은 참가자에게 공개되지 않아요.
- 칭호는 메뉴 → 내 캐릭터에서 장착/해제해요. 이름표 위에 작게 보이고, 단체 사진·숨바꼭질 중에는 숨겨져요.

## 5. 배포 (인터넷 주소로 공개하기)

행사장 Wi-Fi가 기기끼리 통신을 막는 경우(학교 Wi-Fi에서 흔합니다)에는 인터넷에 배포하는 게 가장 확실합니다.
WebSocket을 지원하는 서비스여야 하며, 아래는 **Render** 기준입니다 (`render.yaml` 포함).

1. 이 폴더를 GitHub 저장소에 올립니다.
2. https://render.com 가입 → **New → Blueprint** → 저장소 선택 → 배포.
   (직접 만들 경우: Web Service / Build `npm ci && npm run build` / Start `npm start`)
3. 배포 주소가 나오면 환경변수 `PUBLIC_URL` 에 그 주소를 넣고 다시 배포합니다 (QR 코드용).

> 무료 요금제는 한동안 접속이 없으면 잠들어서 첫 접속이 30초~1분 걸립니다. **행사 시작 10분 전에 미리 한 번 접속**해 깨워두세요.
> 서버를 재배포/재시작하면 참가자는 자동으로 다시 입장하지만, 행사 중에는 재배포하지 않는 것을 권장합니다.

Railway, Fly.io 등 다른 Node.js 호스팅도 같은 명령(`npm run build` → `npm start`)으로 동작합니다.

### 네트워크 동작 요약

- 클라이언트는 자기 위치를 초당 15회 보냅니다 (변화가 있을 때만).
- 서버는 속도와 벽 통과를 검사하고, 바뀐 참가자 위치만 초당 15회 묶어서 보냅니다. 3초마다 전체 위치를 다시 보내 유실을 보정합니다.
- 다른 참가자는 약 140ms 뒤의 과거 시점을 보간해 그리기 때문에 네트워크가 흔들려도 부드럽게 움직입니다.
- 새로고침·잠깐 끊김: 브라우저에 저장된 세션 토큰으로 `resume` → 같은 캐릭터로 복귀. 그동안 다른 사람에게는 반투명 + "연결 끊김"으로 보입니다.
- 서버 재시작: 토큰이 사라져도 저장된 프로필과 마지막 위치로 자동 재입장합니다.

### 2차·3차 확장 포인트

| 기능 | 붙이는 곳 |
| --- | --- |
| 게시판 영구 저장 | 지금은 JSON 파일. 무료 서버는 재배포 시 지워지므로 오래 보관하려면 디스크가 있는 요금제나 외부 DB로 `BoardStore` 교체 |
| 포즈·춤·새 표정 | `art/characters.ts` 시트에 행을 추가하고 `textures.ts`에서 애니메이션 등록 (표정 행 `e` 참고) |
| 새 음식 | `shared/foods.ts` + `FOOD_IDS`에 추가하고 `art/foods.ts`에 그림 함수 추가 |
| 대화·말풍선·이모트 | `WorldOverlay`(DOM 레이어)에 말풍선 요소 추가, 서버 `Room`에서 같은 채널로 브로드캐스트 |
| 놀이터 장난 기믹 | `WorldScene`의 소품(`slide`, `swing` 등)에 상호작용 반경 + 서버 이벤트 |
| '과제 괴물' 레이드 | `Room`을 상속한 `RaidRoom` 생성 → 포털 구역에서 룸 이동 → 클라이언트에 `RaidScene` 추가 |

구역의 개발 단계는 `shared/map.ts`의 `phase` 값(1·2·3)으로 관리하며, 화면의 "준비 중"·"2차 예정" 표시도 여기에서 나옵니다.

## 7. 문제 해결

- **휴대폰에서 접속이 안 돼요** → 노트북과 같은 Wi-Fi인지 확인하세요. 학교 Wi-Fi는 기기 간 통신을 막는 경우가 많으니, 노트북 핫스팟을 쓰거나 5장의 방법으로 배포하세요. Windows 방화벽 허용 창이 뜨면 "허용"을 누르세요.
- **QR 코드 주소가 이상해요** → `PUBLIC_URL` 을 지정하세요.
- **"다른 화면에서 접속했어요"** → 같은 브라우저의 다른 탭에서 같은 캐릭터로 들어간 경우입니다. 테스트할 때는 `?slot=2` 를 쓰세요.
- **게시판 쪽지가 사라졌어요** → Render 무료 요금제는 재배포·재시작 시 디스크가 초기화돼 쪽지(`data/board.json`)가 지워집니다. 행사 중에는 재배포하지 마세요.
- **포트가 이미 사용 중** → 다른 서버가 3000번을 쓰고 있습니다. `$env:PORT=3100; npm start` 처럼 바꾸세요.
